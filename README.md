# Funnel Drop-off Analysis

## Objective

Analyze a signup funnel to measure user conversion between stages and identify the largest drop-off.

## Steps

- Removed duplicate user events
- Counted unique users per funnel stage
- Calculated stage-to-stage conversion rate
- Identified the largest drop-off
- Created a funnel bar chart
- Calculated average time between stages (Bonus)

## Tools

- Python
- Pandas
- Matplotlib
